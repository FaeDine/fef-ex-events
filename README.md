# FEF Exercise #7 - Working with Controls (class starter)

Angular 20 project (NgModule based, `standalone: false`).

```bash
npm install
ng serve
```

Open http://localhost:4200/. The page shows four section headings. Work through the
`TODO` comments in each component with the class demo:

1. `ng-model-demo` - two-way binding with `ngModel`
2. `events` - event binding
3. `select-control` - select bound to the mock data (`models/` and `mocks/` are already done)
4. `draggable-element` - mouse events

Remember your standard exercise comments, then commit, push and post your repo link
(instructor added as a contributor).
